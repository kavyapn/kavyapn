### 👩‍💻 About Me

Data and AI professional with **11+ years of enterprise IT** across finance, healthcare and product companies (ING, Credit Suisse, Yalwa), now pursuing an **M.Sc. in AI & Data Science for Digital Business Management** at Hochschule Furtwangen University (HFU).

- 🤖 Building applied ML and explainable-AI projects: regression, classification, SHAP
- 📊 Turning raw data into decisions with SQL, data warehouses, ETL pipelines and BI dashboards
- ✅ Background in quality engineering and release management, so I care about data quality, validation and models you can trust
- 🧑‍🤝‍🧑 Organizer of **AI Agenten Frankfurt**, a meetup bringing practical AI tools to beginners
- 🏆 Hackathons: FUTURY Build Days (Deutsche Bank challenge), BerlinHack
- 🌱 Currently exploring LLM agents, RAG and AI evaluation

### 🚀 Featured Projects

| Project | What it does | Stack |
|---|---|---|
| **FreightIQ** | Freight price prediction on 386,072 logistics records (FY2022–2025). Test R² **0.967**, MAE ~₹111, multi-stage geocoding + routing cleaning pipeline | Python · Random Forest · SHAP |
| **SmartInvest** | Season-pass purchase prediction for Europa-Park on 10k customers, turned into a win-back campaign for ~1,031 high-potential non-buyers | Python · XGBoost · SHAP |
| **GLP-1 Safety Signals** *(in progress)* | Pharmacovigilance signal detection on FDA FAERS adverse-event reports using PRR and χ², star-schema model and dashboards | SQL · Star schema · Tableau |
| [**PULS / FinWell 360**](https://github.com/kavyapn/Deutsche_Bank_pulse) | Financial-health app with an AI coach for Deutsche Bank's Next Gen challenge at FUTURY Build Days, Frankfurt | Hackathon prototype |
| [**Solar Panel Fault Detection**](https://github.com/kavyapn/Solar-Panel-Fault-Detection) | ML-based fault detection for solar panels | Python · Jupyter |
